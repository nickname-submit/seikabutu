# ARAPメッシュ変形研究

ARAP（As-Rigid-As-Possible）メッシュ変形は、3Dメッシュの局所的な形をできるだけ剛体のように保ちながら、ユーザーが指定した位置までモデルを変形させる手法です。
たとえば、人型モデルの手を別の位置へ動かすと単純に頂点を引っ張るだけでは、腕が伸びたり潰れたりして形が崩れます。この手法では、各頂点の周囲が変形前からできるだけ回転だけで説明できる形になるように変形します。そのため、「位置は大きく変わっても、局所的な形状はなるべく変えない」という変形ができます。
アルゴリズムではエネルギー関数を定義し、それをローカルステップ、グローバルステップで最小化する方法で目的の変形を達成します。
### 詳しくは資料.pdfに記載しています。

研究活動として、ARAPメッシュ変形に、近傍の拡張と回転平滑化項を加えるアルゴリズムの実装をしています。

## 目的

- メッシュの局所的な形状を保ちながら変形する
- 近傍頂点の扱いを拡張して変形結果を比較する
- 回転の滑らかさを評価する項を追加する

## 主なファイル

- `ARAP_addition.cpp`：近傍拡張を加えた実装
- `ARAP_rring.cpp`：回転平滑化項を加えた実装
- `horse.obj`：比較用の元メッシュ
- `horse_R-R.obj`：R-R近傍による変形結果
- `horse_rring.obj`：回転平滑化項を使った変形結果
- `資料.pdf`：研究内容と実験結果の資料
