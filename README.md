# Witch and Hero（ゲーム版）

魔女を守りながら、向かってくるモンスターを斬撃で倒す2Dアクションゲームです。

## すぐ遊ぶ（Unity不要）

GitHubのリポジトリ内にある `Witch-and-Hero-macOS.zip` をダウンロードして展開し、`Witch and Hero.app` を起動してください。

この配布版はMac用のUniversal Binary（Apple Silicon / Intel対応）です。初回起動時はコイン0、未強化、初期ステージから始まります。セーブデータはプレイする端末ごとに保存されます。

macOSの警告が表示された場合は、アプリを右クリックして「開く」を選択してください。開発中のため、Apple notarizationは行っていません。

## ゲームの遊び方

1. タイトル画面で「ステージを選ぶ」を決定します。
2. ワールドマップで解放済みのステージを選び、ステージ情報を確認して開始します。
3. ヒーローを動かし、敵を避けながら斬撃でモンスターを倒します。
4. ヒーローが倒される前に魔女を守り、敵を全滅させるとクリアです。
5. 敵が落とすコインは強化ツリーで使い、経験値はバトル中の魔女の全体攻撃スキルに使います。

## 操作

- **WASD / 矢印キー**: ヒーロー移動、ステージ選択画面の移動
- **Enter / Space**: 決定
- **Esc**: 戻る・キャンセル
- **ステージ選択画面**: ドラッグ、トラックパッドの2本指操作、またはWASDでマップ移動
- **攻撃・スキル**: 画面内のボタンまたは表示されるキー操作

## セーブデータとリセット

コイン、ステージ解放状況、強化状況は端末内に保存されます。開発者のプレイデータは配布ファイルやGitHubには含まれません。

強化画面にはコインと強化をリセットする機能があります。

## Unityで開く場合

`Witch and Hero.zip` をダウンロードし、Unity **6000.5.6f1** で開いてください。`Assets/Scenes/MapScene.unity` と `Assets/Scenes/SampleScene.unity` がゲームのシーンです。

# ARAPメッシュ変形への近傍拡張と回転平滑化項の追加

本リポジトリは、卒業研究として実装した As-Rigid-As-Possible（ARAP）ベースの3Dメッシュ変形システムをまとめたものです。

本実装では、ARAPメッシュ変形を基礎として、**近傍構造の拡張（r-ring）** および **エネルギー関数の追加項（R-R）** をそれぞれ独立に導入し、変形品質と表現能力の改善を目的としています。

詳細は **資料.pdf** に書いているため省きます．なお，実行にはEigenとlibiglを使用しており，それぞれ行列の基本的な計算や特異値分解，AABB木を用いたレイ交差判定処理を行なっています．

---

## 研究目的

- ARAPベースの安定したメッシュ変形の実装
- LSRVによる自動関節判定
- 近傍構造の拡張による局所情報の強化（r-ring）  
- エネルギー関数の拡張による変形自由度の向上（R-R）  

---

### ARAP_rring.cpp : 近傍構造の拡張（r-ring）

計算に用いる近傍を，その頂点に接続する頂点集合から，r回の隣接移動で到達できる頂点集合に拡張します．
これにより、局所情報の偏りを抑制し、変形の安定性を向上させます。

---

### ARAP_addition.cpp : 回転平滑化項（R-R）

本実装ではARAPのエネルギー関数に対して追加項（R-R）を導入しています。
この項は近くの頂点での変化量を抑制する働きを持ち、変形挙動の自由度および安定性に影響を与えます。

---

### 各オブジェクトファイル (*.obj)
- horse.obj      :実験に使用したサンプルファイル
- horse_rring.obj:ARAP_rring.cppで変形したメッシュ
- horse_R-R.obj  :ARAP_addition.cppで変形したメッシュ

変形したメッシュの色は赤色の部分が自動関節判定により関節と半知恵された部分であり，計算では青い部分に比べて変形しやすく扱われています．
