# Witch and Hero

魔女を守りながらモンスターを倒す、ステージ攻略型の2Dアクションゲームです。

## すぐに遊ぶ（Mac）

1. `Witch-and-Hero-macOS.zip` をダウンロードして展開します。
2. `Witch and Hero.app` を起動します。
3. macOSの警告が表示された場合は、アプリを右クリックして「開く」を選びます。

このアプリはIntel MacとApple Silicon Macの両方に対応したUniversal Binaryです。ゲームデータはアプリ内に含まれています。

## ゲーム内容

- ワールドマップでステージを選択して出撃します。
- 魔女を守りながら、出現するモンスターをすべて倒すとクリアです。
- ヒーローの斬撃、魔女のスキル、ノックバック、敵ごとのステータスがあります。
- 敵を倒すと経験値とコインを獲得できます。
- 経験値はゲーム中の魔女のスキル、コインはステージ間の強化に使用します。
- ステージ10にはボス、後半ステージにはミニボスが出現します。

## 操作

- タイトル・メニュー：決定キー（Enter / Space）
- ステージ選択：クリック、ドラッグ、WASDまたは矢印キー
- バトル：WASDまたは矢印キーで移動、攻撃キーで斬撃、スキルキーで魔女の範囲攻撃

画面内の操作説明でもキーを確認できます。

## セーブとリセット

コイン、クリア状況、強化状況は端末のローカルデータに保存されます。配布版は初期状態から始まります。ゲーム内のリセット機能を使うと、保存された進行状況を初期化できます。

## Unityプロジェクトとして開く

`Witch and Hero.zip` を展開し、Unity Hubからプロジェクトとして追加してください。使用Unityバージョンは `6000.5.6f1` です。

## ファイル構成

- `Witch-and-Hero-macOS.zip`：そのまま遊ぶためのMac版アプリ
- `Witch and Hero.zip`：編集・ビルド用のUnityプロジェクト
